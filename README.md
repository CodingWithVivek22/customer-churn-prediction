# Customer Churn Prediction

A Customer Churn Prediction project built using PyTorch and FastAPI. The project uses an Artificial Neural Network (ANN) to predict whether a customer is likely to churn based on customer and service information.

## Features

- Artificial Neural Network (ANN)
- Data preprocessing
- Feature scaling
- FastAPI REST API
- Customer churn prediction

## Tech Stack

- Python
- PyTorch
- Pandas
- Scikit-learn
- FastAPI

## Run Locally

Clone the repository:

git clone https://github.com/CodingWithVivek22/customer-churn-prediction.git

cd customer-churn-prediction

Install dependencies:

pip install -r deployement/requirements.txt

Run the API:

cd deployement

uvicorn app:app --reload

The API will be available at:

http://127.0.0.1:8000

API documentation:

http://127.0.0.1:8000/docs
